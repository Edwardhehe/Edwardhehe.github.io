CAD 批量打印插件

v1.15.7.6

同时支持中望 CAD与AutoCAD 2015-2027的批量打印与批量拆图插件。 支持图框库学习与识别、跨 DWG 扫描、通用型矩形批打、单张框选打印、PDF/PNG/JPG/DWF/DWG 多格式输出、PDF 合并、CAD 原生预览、图纸目录，以及按图框拆出轻量 DWG。

  • 图框库批量打印：学习图框后识别图号、图名、图幅与比例；支持动态块可见性与套用已有图框。
  • 通用型矩形批打与单张框选打印；外框支持闭合矩形与四线拼合，多文件按文件名/图号排序。
  • 多格式输出 PDF、PNG、JPG、DWF、DWG；PDF 可合并并可选保留单页；支持 CAD 原生预览。
  • 多文件批打可按源文件选择打印样式；扫描结果可累加；支持图纸目录与清单编辑。
  • 按图框拆 DWG，保留相交图元与 XCLIP 裁剪块；自动安装 LA_pdf / LA_png / LA_jpg / LA_dwf。
  • 发布包分三组：中望 CAD、AutoCAD 2015-2024、AutoCAD 2025-2027。

DesktopMemoWin

v1.4.1

基于 .NET 8 和 WPF 的 Windows 桌面备忘录。 用月历展示每天待办，支持系统托盘、回收站、开机启动、侧边便签，以及本地数据备份恢复。

  • 支持月历视图和列表视图，适合日常快速记录与回顾。
  • 支持完成状态、优先级、置顶、软删除和当日任务窗口。
  • 支持紧贴主界面的侧边便签，可粘贴文字和图片，并自动保存。
